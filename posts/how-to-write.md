새 글은 `posts` 폴더에 `.md` 파일을 하나 만들면 됩니다.
파일 이름이 글 주소가 되므로 `my-first-post.md`처럼 **영문 소문자와 하이픈**을 쓰는 것을 추천합니다.

## 1. 파일 맨 위에 글 정보 쓰기

파일은 아래처럼 `---` 사이에 글 정보를 적고 시작합니다.

```markdown
---
title: 글 제목
date: 2026-10-14
tags: [태그1, 태그2]
description: 목록에 보일 짧은 요약
---

여기서부터 본문을 씁니다.
```

## 2. 블로그 열기

바탕화면의 **블로그** 아이콘을 더블클릭하면 글 목록이 자동으로 갱신되어 새 글이 나타납니다.
이미 열려 있다면 브라우저를 새로고침하세요.

> 파일 이름이 `_`로 시작하거나 `draft: true`가 있으면 목록에 나오지 않습니다. 임시 저장용으로 쓰세요.

## 지원하는 문법

### 글자 꾸미기

**굵게**, *기울임*, ~~취소선~~, ==형광펜==, `인라인 코드`를 쓸 수 있습니다.
[링크](https://developer.mozilla.org)도 넣을 수 있고, 같은 글 안의 [제목으로 이동](#표)할 수도 있습니다.

### 목록

1. 첫 번째
2. 두 번째
   - 중첩된 항목
   - 또 하나
3. 세 번째

- [x] 블로그 만들기
- [ ] 글 열 개 쓰기

### 코드 블록

```javascript
function greet(name) {
  return `안녕하세요, ${name}님!`;
}

console.log(greet('독자'));
```

### 표

| 문법 | 결과 | 비고 |
| :--- | :---: | ---: |
| `**굵게**` | **굵게** | 가장 많이 씀 |
| `*기울임*` | *기울임* | |
| `~~취소~~` | ~~취소~~ | GFM 확장 |
